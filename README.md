To solve this problem I created a list called 'profiler', that would emulate the call stack by adding and storing all names of the functions, that come from call stack samples. If the function name is present in profiler, but not present in the stack frame, then that's how I know, that the function ended executing. If the size of the profiler is less then a size of stack in the sample (in other words it has less elements inside the list), then that's how I know, that a function started executing. So this approach basically allowed me to solve this problem.
